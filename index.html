Control your mouse with your keyboard

Point, click, drag, and scroll without leaving the keyboard. Currently supports Sway on Wayland.

Install Try it in your browser

How it works

Point anywhere in a few keystrokes

A labelled grid covers the screen. Type a cell's label, then press an action key.

  • AltSpaceOpen the grid
  • a to zSelect a cell
  • sdfLeft, middle, or right click

Zoom in on small targets

Press Return to split the selected cell into a finer grid, shown in an optional magnifying lens.

  • ReturnRefine the selection
  • BackSpaceGo back a level
  • cDouble-click

Move, drag, and scroll

Mouse mode moves the pointer while a direction key is held, with smooth acceleration. Hold a button key while moving to drag.

  • hjklMove
  • sdfHold a button
  • ueyoScroll

Configure every detail

Keys, colours, grid density, and motion curves live in one TOML file. mousr reload applies changes without a restart.

Configuration reference

~/.config/mousr/config.toml
[grid]
refinement_zoom = 4.0
unmatched = "dim"

[motion]
curve = "ease-in-out"
initial_speed = 60.0
max_speed = 1800.0

[bindings.mouse]
left = "h"
down = "j"
up = "k"
right = "l"

Installation

Mousr currently supports Sway on Wayland only.

1Install
Download amd64 Download arm64

Or optionally use this helper script to install.

curl -fsSL https://mousr.toxdes.com/install | sh
Archives do not include runtime libraries.

Install libwayland-client0 and libxkbcommon0 on Debian/Ubuntu, wayland-libs and libxkbcommon on Fedora, or wayland and libxkbcommon on Arch.

1. Set up the repository

sudo install -d /etc/apt/keyrings
curl -fsSL https://packages.toxdes.com/apt/pubkey.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/toxdes.gpg
echo 'deb [signed-by=/etc/apt/keyrings/toxdes.gpg] https://packages.toxdes.com/apt stable main' | sudo tee /etc/apt/sources.list.d/toxdes.list >/dev/null

2. Install Mousr

sudo apt update && sudo apt install mousr

Runtime dependencies (libxkbcommon and the Wayland client library) install automatically.

1. Set up the repository

sudo rpm --import https://packages.toxdes.com/rpm/pubkey.gpg
sudo tee /etc/yum.repos.d/toxdes.repo >/dev/null <<'EOF'
[toxdes]
name=Toxdes packages
baseurl=https://packages.toxdes.com/rpm
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://packages.toxdes.com/rpm/pubkey.gpg
EOF

2. Install Mousr

sudo dnf makecache && sudo dnf install mousr

Runtime dependencies (libxkbcommon and the Wayland client library) install automatically.

# Latest tagged release, built from source

Runtime dependencies (libxkbcommon and the Wayland client library) install automatically.

Requires a stable Rust toolchain from rustup.

1. Install the build dependencies: Ubuntu / Debian

sudo apt install pkg-config libxkbcommon-dev libwayland-dev

Fedora

sudo dnf install pkgconf-pkg-config libxkbcommon-devel wayland-devel

Arch

sudo pacman -S --needed base-devel libxkbcommon wayland

2. Build and install

cargo install mousr
2Configure Sway
~/.config/sway/config
exec mousr daemon

# Alt+Space: grid mode
bindsym Mod1+space exec mousr grid

# Alt+Shift+Space: mouse mode
bindsym Mod1+Shift+space exec mousr mouse
3Start Mousr

Apply the bindings and start the daemon in the current session. Later sessions start it from the exec line.

swaymsg reload && swaymsg exec mousr daemon

Press Alt Space to open the grid. See the configuration reference for settings.
